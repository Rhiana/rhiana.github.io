From tables, to floats, to flex, to grid, from Bootstrap to Tailwind to CSS modules and more, CSS has evolved and changed a lot over the years. Whether creating a design system or just trying to center a button, CSS is a powerful and often misunderstood part of software development.

In this session we will go back to basics, learning the fundamentals of CSS and applying them in your very own CSS Zen Garden project. CSS Zen Garden was introduced in 2013, all designs start with the same HTML file and rely on just the power of CSS to make unique and eye catching designs.

No experience with CSS or HTML or code is required. Participation requires minimal set up as it has been designed to empower everyone to create an entry by the end of the session that is unique to them.
